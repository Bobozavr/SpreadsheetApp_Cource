# Исходный код с авторскими записями

Здесь сохранены все 14 исходных Java-файлов из резервной копии перед изменением структуры — вместе со всеми комментариями и закомментированными вариантами кода, без редактирования содержимого.

Расширение .java.txt позволяет читать их в IDEA и не включать старые классы в сборку. Особенно полезен Main.java.txt: в нём остался прежний вариант обработки команд через switch и пояснения к нему.

Рабочая версия находится в src/main/java/spreadsheet. Эти файлы — учебные записи о прежней версии, поэтому названия пакетов и некоторые участки кода отличаются от текущих.
