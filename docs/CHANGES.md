# Изменения структуры и интерфейса

- Java-пакеты разделены на `app`, `console`, `command`, `model`, `view`.
- Класс `spreadsheet` переименован в `Spreadsheet` по принятому стилю Java.
- `Main` только запускает консоль; удалён старый закомментированный вариант программы.
- Мапа команд и интерфейс `Command.execute` сохранены.
- Диспетчер передаёт весь остаток строки команде; `edit` сохраняет пробелы в значении, файловые команды принимают пути с пробелами и внешними кавычками.
- `close` использует тот же Scanner, что и консоль. Конец ввода завершает консоль без исключения.
- Таблица получила заголовки R/C, границы и ширину столбцов по значениям. Справка уточняет синтаксис save.
- CSV-примеры перенесены в examples, исходный Word — в docs.
- Добавлена сборка запускаемого JAR на Java 17+.

Математические правила и ограничения CSV сохранены; они перечислены в README. Полная проверка и исправление этих ограничений остаются отдельным этапом.
