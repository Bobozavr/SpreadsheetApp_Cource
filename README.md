# SpreadsheetApp

Учебная консольная программа на Java: открытие CSV, редактирование ячеек, простые формулы и сохранение таблиц.

## Структура

```text
src/main/java/spreadsheet/
  app/Main.java                 точка входа, запускает консоль
  console/                      ввод и диспетчер команд
  command/                      интерфейс Command и отдельные команды
  model/                        таблица, ячейка и типы данных
  view/TablePrinter.java        оформление таблицы
examples/                       два исходных примера CSV
docs/                           исходная пояснительная записка и заметки
build.ps1                       сборка без сторонних библиотек
dist/SpreadsheetApp.jar          результат сборки
build/                          временные скомпилированные классы
```

## Сборка и запуск

Нужен JDK 17 или новее для сборки, Java 17 или новее для запуска. В PowerShell перейди в папку проекта.

```powershell
.\build.ps1 -JdkHome "C:\Users\shuri\.jdks\openjdk-25.0.1"
java -jar .\dist\SpreadsheetApp.jar
```

Если `java` не найдена, используй полный путь. На текущем компьютере:

```powershell
& "C:\Users\shuri\.jdks\openjdk-25.0.1\bin\java.exe" -jar .\dist\SpreadsheetApp.jar
```

Если PowerShell запрещает выполнение скрипта, для одного запуска сборки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -JdkHome "C:\Users\shuri\.jdks\openjdk-25.0.1"
```

Полный путь к JAR тоже поддерживается. Относительные пути к CSV отсчитываются от текущей папки терминала, а не от расположения JAR. При запуске из другой папки передавай полный путь к CSV.

## Команды внутри программы

```text
help
open examples/test.csv
edit 1 1 200
edit 1 3 "Hello world"
edit 1 4 =R1C1 + R1C2
print
saveas "result table.csv"
close
yes
open "result table.csv"
exit
```

`save <file>` и `saveas <file>` требуют имя файла и могут перезаписать существующий файл. `exit` не сохраняет автоматически. Строки и столбцы считаются с 1. Редактировать можно только существующие ячейки.

## Как устроена обработка

`Main` запускает `Console`. Консоль читает строку и передаёт её в `CommandDispatcher`. Диспетчер получает объект команды из `Map<String, Command>` и вызывает `execute`, передавая оставшийся текст аргументов и таблицу. Каждая команда разбирает собственные аргументы. Выбор команды не использует цепочку `if` или `switch`.

`Spreadsheet` хранит строки ячеек. `Cell` распознаёт тип значения и вычисляет простые формулы при выводе. `TablePrinter` добавляет заголовки R/C и подбирает ширину столбцов по содержимому. При сохранении записываются исходные формулы, а не показанные результаты.

## Текущие ограничения

Это организация существующего проекта, а не полная переработка вычислителя.

- Формула: два адреса вида `R1C1`, один оператор `+`, `-`, `*`, `/`, одиночные пробелы вокруг оператора.
- Числовые константы, скобки и цепочки операций внутри формулы не поддерживаются.
- Ссылка на ячейку с формулой пока даёт ноль вместо её вычисленного результата.
- Пустые и отсутствующие ячейки дают ноль; деление на ноль тоже возвращает ноль.
- CSV пока разделяется по запятым без полноценной поддержки кавычек: запятые внутри строк не поддерживаются; конечные пустые ячейки теряются.
- Слишком большое целое число в открываемом файле может вызвать исключение.
- Открытие другого файла заменяет таблицу без предупреждения о несохранённых изменениях.

Исходный Word в `docs` сохранён без изменений и описывает старую архитектуру. Для текущей структуры используй этот README и `docs/CHANGES.md`.
